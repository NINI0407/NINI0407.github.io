啟動平台對戰

2025年09月25日 DarkChess

秉鈞學長程式(Windows)

  1. 編譯指令
    Chinese_Dark_Chess_Program\alphabeta+parallel+endgame_database_tradinational 資料夾下
  2. 直接點兩下開RUN_ALL.bat/RUN_OPEN.bat/RUN_ENTER.bat開啟平台
  3. 設定好平台參數就可以跟別人對戰了 (open要先開始遊戲，enter才能找得到房號)
    • 把編譯檔放到平台中「AI路徑」欄位中
    • 帳號：可以自己設定，但用a0、a1比較不會出bug
    • 密碼：隨便設
    • 啟動模式：自己選，只要兩個檔相反就行(平常測試可以開本地)
    • 連接模式：讀檔

ps 這支程式目前只能在windows上面執行，在linux環境中即使重新編譯也會有找不到move.txt的問題，下面做了一些嘗試

想法：因為學長的程式只能在windows上運作，wsl又是基於windows的linux應該可以跑AlphaZero(MiniZero)，所以想說可以試試看。

嘗試2：windows跑秉鈞學長程式，linux/wsl跑AlphaZero(MiniZero) ->成功

想法：不要用本地模式，把兩個程式都跑在北大(IP=120.126.151.213)的機器上

流程

windows跑秉鈞學長程式 (open)

  1. 用上面的那個方法就可以了 (!!! 要把本地測試關掉)

linux/wsl跑AlphaZero(MiniZero) (enter)

  1. 設定好DarkChess.config檔(參數請看下面minizero的第一步) (!!! LocalServer=false)
  2. 執行 bash scripts/start-container.sh 啟動minizero的環境容器
  3. 進入容器後執行 java -jar platform/enter/Launcher.jar開啟平台

Minizero(Linux)

  1. 啟動 mgtp 時的 DarkChess.config

  2. 到DarkChess.config檔設定平台參數

    • Arg=/workspace/minizero/environment/darkchess/mgtp.py /workspace/build/darkchess/minizero_darkchess -mode console -conf_file /workspace/darkchess-az-eval.cfg -conf_str nn_file_name\=/workspace/darkchess_az_model_reward_500sim/model/weight_iter_75000.pt
    • SearchPath=/usr/bin/python3
    • Account=可以自己設定，但用a0、a1比較不會出bug
    • Password=隨便設
    • StartMode=自己選，只要一個open一個enter就行
    • ConnectMode=MGTP

  3. bash scripts/start-container.sh會啟動環境容器

  4. 進入容器後執行bash run-platform-eval.sh

    啟動容器後在容器中直接跑 run-platform-eval.sh 會開兩個 tmux 視窗對戰

    出現 run-platform-eval.sh: line 4: tmux: command not found 錯誤 執行 在容器中重新下載即可
Start Calling Local Server (平台訊息)

這其實也不算error，這個意思只是開到了本地模式，會導致用run-platform-eval.sh 啟動minizero的時候卡住
解決
在DarkChess.config設定檔中設定LocalServer=false

讓 Lightzero 和 minizero 對戰

ps 3depth、mgtp(這兩個是平台隨機下棋的版本)

MiniZero vs LightZero與平台對接的邏輯

訓練好的模型不能直接匯入平台，要透過一個mgtp檔對接平台跟模型，這個檔主要由兩部分組成

  1. 啟動模型
    MinniZero
    只需實作開一個subprocess，並執行build好的執行來啟動模型(他會自行載入policy、模型網路、環境 (env)、其他內部參數)

    subprocess

    可以想成是用程式碼開一個terminal，可以用程式碼的方式輸入指令、讀輸出
    eg.
    b.py

    a.py

    執行結果
    Hello bubu!


    LightZero
    要建立一個muzero模型物件，載入訓練好的模型(.pth檔)，接著呼叫lzero.policy中函式讓模型推理並產生走步

  2. 實作MGTP通訊結構
    MiniZero
    對戰平台 ←→ mgtp.py ←→ minizero console 程式，mgtp檔單純轉發stdin/stdout，由concole處理mgtp命令和AI邏輯


    LightZero
    對戰平台 ←→ mgtp.py ←→ LightZero 模型，要處理 MGTP 命令，並呼叫模型推論
